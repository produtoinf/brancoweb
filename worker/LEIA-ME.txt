BRANCO — PAINEL (WORKER COMPLETO)

Arquivo para subir:  worker.js   (servidor + banco de dados + painel, tudo num arquivo só)

COMO COLOCAR NO AR (pelo site da Cloudflare, sem instalar nada)

1) Criar o Worker
   Cloudflare > Workers & Pages > Create > Worker
   Nome: branco-admin  >  Deploy  >  "Edit code"
   Apague todo o código que aparece, cole o conteúdo do worker.js e clique em Deploy.

2) Criar o banco de dados
   Cloudflare > Storage & Databases > D1 > Create database
   Nome: branco

3) Ligar o banco no Worker
   Worker branco-admin > Settings > Bindings > Add > D1 database
   Variable name: DB      Database: branco      > Save

4) Criar a senha do painel
   Worker branco-admin > Settings > Variables and Secrets > Add
   Type: Secret     Name: ADMIN_SENHA     Value: (sua senha)   > Save

5) Abrir o painel
   https://branco-admin.SEU-USUARIO.workers.dev/admin
   (as tabelas do banco são criadas sozinhas no primeiro acesso)

6) Ligar o site ao painel novo
   No arquivo track.js do site, troque o endereço da linha
     const API = 'https://branco-admin.brancowebs.workers.dev';
   pelo endereço do seu Worker novo.

PROSPECÇÃO COM TOMTOM (grátis, 2.500 buscas por dia, sem cartão) — recomendado
   1. developer.tomtom.com > Register > confirme o e-mail
   2. No Dashboard, copie a chave "My first API key" (ou crie uma em Keys)
   3. Worker branco-admin > Settings > Variables and Secrets > Add > Secret
      Name: TOMTOM_KEY   Value: (a chave)

PROSPECÇÃO COM HERE (grátis, plano Limited, sem cartão)
   1. platform.here.com > crie a conta (plano gratuito)
   2. Access Manager > Apps > crie um app > API Keys > Create API key > copie
   3. Worker > Settings > Variables and Secrets > Add > Secret
      Name: HERE_KEY   Value: (a chave)

TELEFONE PELA PESQUISA DO GOOGLE (opcional, recomendado — sem cartão)
   1. Crie uma conta em serper.dev e copie a "API Key" (vem com créditos grátis)
   2. Worker branco-admin > Settings > Variables and Secrets > Add > Secret
      Name: SERPER_KEY   Value: (a chave)
   Pronto: quem vier sem celular tem o telefone procurado sozinho na pesquisa do Google.
   (1 a 2 créditos por estabelecimento sem celular)

PROSPECÇÃO COM GOOGLE MAPS (opcional, bem mais completo que o OpenStreetMap)
   1. console.cloud.google.com > crie um projeto > ative "Places API (New)" (precisa de conta de faturamento;
      o Google dá uma cota grátis por mês — crie um alerta de orçamento para não ter surpresa)
   2. APIs e serviços > Credenciais > Criar chave de API > restrinja a chave à "Places API (New)"
   3. Worker branco-admin > Settings > Variables and Secrets > Add > Secret
      Name: GOOGLE_PLACES_KEY   Value: (a chave)
   Com a chave, quem vier sem celular (TomTom/HERE) tem o telefone completado sozinho pelo Google.
   Sem a chave, a prospecção usa o OpenStreetMap (grátis, mas com menos estabelecimentos).

O QUE O WORKER FAZ
- Conta visitas, cliques no WhatsApp, formulário aberto e cadastros do site (track.js)
- Painel /admin: visão geral com gráficos, follow-up, financeiro, clientes
- Prospecção: busca estabelecimentos por nicho e cidade, salva no follow-up e abre a sequência de mensagens
- Aviso "site em atualização" (liga/desliga no painel)
- Área do cliente: cada cliente ganha um link secreto /cliente/... com andamento do projeto,
  recado, próximo passo, links/arquivos e as visitas do site dele (gráfico, origem, aparelho, páginas)
- Contador de visitas para sites de clientes (/c.js)

BANCO ANTIGO
- Pode usar o mesmo banco D1 do painel antigo: o Worker cria sozinho as colunas que faltam
  (sem apagar nada) e gera o link da área de cada cliente que já existia.

OBSERVAÇÕES
